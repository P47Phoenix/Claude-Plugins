# UI/UX

**Invocation**: `delivery-team:ui`

UI/UX design agent for crafting user experiences, visual designs, and game interfaces.

## Roles

### UX Designer

User research, flows, wireframes, and information architecture.

**Task signals**: "user flow", "journey map", "persona", "wireframe", "usability", "information architecture", "card sorting"

### UI Designer

Design systems, component specs, visual design, and accessibility.

**Task signals**: "design system", "design tokens", "component spec", "WCAG", "accessibility", "interaction design", "micro-interaction"

### Game UI Designer

HUD design, game menus, inventory UI, and game-specific interface patterns.

**Task signals**: "HUD", "game menu", "inventory UI", "health bar", "minimap", "dialog system", "quest log", "crafting UI"

## Key Capabilities

- User flow diagrams and journey maps
- Wireframe specifications
- Design system documentation (tokens, components, patterns)
- Accessibility review (WCAG compliance)
- Game UI layout and HUD design
- Interaction design and micro-animations

## Example Usage

```
User: "Create a user flow for the checkout process"

Role: UX Designer | Task: user-flow
References: ux-research.md, interaction-patterns.md

Output: User flow diagram with decision points, error states,
        edge cases, and accessibility considerations
```
