### 3. [BLOCKING] Fixed `config_version` vs `schema_version` mismatch (FINDING-07)

**File:** `hardware-team/hooks/validate_session.py` (lines 81, 83-84, 88)
**Root cause:** `validate_session.py` used `config_version` but the config schema (config-schema.md) and `validate_config.py` both use `schema_version`.

Changed all 3 occurrences of `config_version` to `schema_version` in `validate_session.py`:
- `config.get("config_version", "")` -> `config.get("schema_version", "")`
- Regex pattern `config_version:` -> `schema_version:`
- Warning message `missing config_version field` -> `missing schema_version field`

**Tested:** Script executes without error and correctly reports missing config.
