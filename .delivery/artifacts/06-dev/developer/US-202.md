## Design Decisions

1. **Model tier in frontmatter is Sonnet (not Sonnet+):** Architecture Section 10.4 specifies Sonnet for the EE role and Sonnet+ for the Schematic Review Gate specifically. The SKILL.md frontmatter matches the role tier (Sonnet); the body documents the gate requirement (Sonnet+).
2. **6 task types (not 5):** Added `firmware-interface` and `signal-integrity` as explicit task types in addition to the 3 specified in AC. The architecture (Section 2.1, artifact layout, and C4 diagram) clearly expects these as distinct outputs.
3. **Sourcing priority order:** DigiKey > Mouser > LCSC > element14, matching the architecture's Section 5.2 and the practical priority of prototype-first sourcing.
4. **Unavailability handling pattern:** Follows architecture Section 5.3 exactly -- report SKILL_UNAVAILABLE, note degradation, continue with best judgment, never reimplement.
