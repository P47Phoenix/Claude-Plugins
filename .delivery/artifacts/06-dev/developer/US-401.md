## Key Design Decisions

1. **Named personas (Vera, Netty, Professor Surge, Dr. Priya, Marco)**: Not cosmetic -- behavioral differentiation in prompted output improves forced-find depth in specialty areas. Marco is the generalist dispatched on every run.

2. **Coverage-based stopping over convergence**: Per architecture F-11 resolution, we track which categories are examined rather than looking for finding overlap. Two-clean and class-saturation are optional enhancements behind config flags.

3. **Deterministic dedup only**: No LLM inference in the dedup step. Gate decisions must be reproducible. Component+category matching for component-level, net+category for net-level, category+board_issue_id for board-level.

4. **Sonnet+ for all reviewers**: Per architecture Section 10.4 and issue #76 learnings. Haiku acceptable only for documentation-only review (not the gate itself).

5. **Parallel dispatch in single message**: All N reviewer Agent tool calls go in one orchestrator response for true parallel execution.
