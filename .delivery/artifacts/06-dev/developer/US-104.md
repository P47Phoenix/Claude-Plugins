## Design Decisions

1. **PyYAML fallback**: Script includes a minimal YAML parser fallback if PyYAML is not installed, since yaml is not part of the Python stdlib. The fallback handles the subset of YAML used by config files.
2. **Exit codes**: 0 = valid (with or without warnings), 1 = file not found, 2 = structural error. Warnings never cause non-zero exit.
3. **Forward compatibility**: Unknown top-level keys are reported as INFO, never error/warning. This matches the architecture's forward compatibility protocol.
4. **Pure YAML**: Config is pure YAML per memory lesson -- no markdown frontmatter delimiters.

## Test Results

- Valid config: `Config valid. All fields match schema v1.0.` (exit 0)
- Invalid values (11 bad fields + 1 missing required): 11 warnings + 1 error reported correctly (exit 2)
- Missing file: `ERROR: Config file not found` (exit 1)
- Empty file: `ERROR: Config file is empty.` (exit 2)
