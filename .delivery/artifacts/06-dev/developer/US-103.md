## What Was Built

### 1. `hardware-team/skills/hardware-flow/references/quality-gates.md`

Complete gate criteria for all 8 pipeline stages covering:

- **Severity definitions**: Critical, Major, Minor, Info with precise hardware examples
- **Gate strictness behavior**: strict/standard/relaxed matrix per `gate_strictness` config
- **Self-correction protocol**: max iteration limits, escalation rules, waiver protocol with state recording
- **8 gate definitions** with DoD validator assignments:
  1. Concept Gate (2 validators: requirements-completeness, feasibility-check)
  2. Schematic Review Gate (7 category validators with multi-reviewer iterative pattern, forced-find prompting, deterministic dedup, coverage check)
  3. DRC Gate (impedance control, thermal analysis, fab-specific manufacturing constraints)
  4. Human Confirmation Gate (gate-in/human-action/gate-out for Stages 4 and 7)

  6. BOM Gate (cost validation, availability, lifecycle status, second-source)
  7. Compliance Gate (EMC checklist per FCC/CE, safety per IEC 62368-1/UL, environmental per RoHS/REACH/WEEE)
  8. Final Gate (aggregate check -- all prior gates DONE/WAIVED, all artifacts exist)
- **Design Review Board protocol**: multi-role independent review, deterministic dedup, unified severity ranking
- **Board Issue ID enum**: 8 defined IDs for board-level finding deduplication
- **DoD validator assignment summary table**

- [x] Each validator has: unique ID, description, pass/fail criteria, responsible role

## Decisions Made

1. **Self-correction limit reuses rework config**: `max_rework_iterations` (default 3) governs both per-gate self-correction and per-path rework. Single config key, consistent behavior.
2. **Waiver recording**: Waivers stored in gate results with `result: WAIVED`, `waiver_reason`, and `waived_findings[]`. Final Gate checks for waivers and logs warnings.
3. **DFM/BOM parallel execution**: Both validators run concurrently within Stage 5 gate since they have no data dependency on each other.
4. **DRB activation points**: After Schematic, Layout, and DFM/DFA stages (3 transition points).
