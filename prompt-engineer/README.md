# Prompt Engineer

Expert prompt optimization for LLMs and AI systems. Proactively improves prompts using proven techniques, patterns, and model-specific optimization.

## Overview

This skill helps craft, optimize, and evaluate prompts for any LLM. It applies comprehensive prompt engineering techniques and always shows the complete prompt text rather than just describing what a prompt should be.

## Features

- **Prompt engineering techniques**: Chain-of-Thought, few-shot, role-playing, self-consistency, Tree of Thoughts
- **Model-specific optimization**: Claude, GPT, open source models
- **Advanced patterns**: Constitutional AI, prompt chaining, self-reflection
- **Evaluation framework**: Clear criteria for measuring prompt quality
- **Proactive assistance**: Automatically helps when AI/LLM usage is detected

## When to Use

- Building AI features or agent systems
- Optimizing agent performance
- Crafting system prompts
- Troubleshooting AI output quality
- Establishing prompt standards for a team

## Installation

```
/plugin install prompt-engineer
```

## Usage

The skill triggers automatically when working with prompts, AI features, or LLM integrations. Examples:

- "Help me write a system prompt for a code review agent"
- "Optimize this prompt for better accuracy"
- "What prompt engineering technique should I use for this task?"

## Key Principle

Always displays the complete prompt text in a clearly marked section. Never just describes what a prompt should be.
