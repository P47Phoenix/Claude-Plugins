# Sprint Review

**Detection keywords**: "sprint review", "what we delivered", "sprint demo", "end of sprint"

**Pipeline auto-detection**: UAT after acceptance.

**Required artifacts**: Sprint plan, UAT report/completion data.
**Enhancing artifacts**: FKCs, metrics, retrospective, defect log.

**Narrative arc**: Outcome-led — completed scope, supporting metrics, lessons learned, next steps. See `references/narrative-patterns.md` for the per-type pattern.

**Audience defaults**: Stakeholder/executive blends; default to technical when not specified.
