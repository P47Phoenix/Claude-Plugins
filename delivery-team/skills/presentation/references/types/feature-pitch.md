# Feature Pitch

**Detection keywords**: "pitch", "propose", "sell this feature", "why we should build", "feature pitch"

**Pipeline auto-detection**: Idea checkpoint.

**Required artifacts**: Idea brief or PRD.
**Enhancing artifacts**: Architecture overview, competitive analysis.

**Narrative arc**: Problem-Solution-Result — the user pain, the proposed feature, the predicted outcome. See `references/narrative-patterns.md`.

**Audience defaults**: Executive or investor; framing pass restructures heavily.
