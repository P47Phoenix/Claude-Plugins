# Section Roles

Each labelled section has a job. Know the job before writing the lines; when extending an existing lyric, give the new section the job its position implies.

## Roles

| Section | Job | Lyric habits |
|---------|-----|--------------|
| Verse N | Advance the story or add a detail | Concrete, new information each time; same meter as other verses |
| Pre-Chorus N | Build tension toward the chorus | Shorter lines, rising question or pressure, ends unresolved |
| Chorus | State the song's claim | Hook line, plain language, repeated verbatim |
| Post-Chorus | Extend the chorus feeling | Short chant or tag; no new plot |
| Bridge | Change perspective or time | New angle, often a turn in the arc; different imagery from the verses; may differ in meter |
| Tag, Outro | Close | Repeat or soften the hook; no new plot |
| A1/A2/B/A3 | AABA form | A sections share meter and rhyme; B contrasts in image and rhyme |

## Rules of thumb

- A new verse repeats the verse meter and rhyme scheme and moves the story forward one step; it never retells the previous verse.
- A bridge borrows the verse's voice but turns the angle: the first time the narrator looks ahead, looks back, or admits something.
- A pre-chorus sets up the chorus's first line, so its last line should lead into the hook without using it.
- An extra chorus repeats the original chorus words; vary only if the arc calls for a changed final line.
- Position decides tone: early sections set scene, late sections resolve.

## Extending a supplied lyric

1. List the source sections and what each one does.
2. Find the gap in the arc (missing turn, missing resolution, missing build).
3. Name the new section's job in one sentence before writing.
4. Copy the meter and rhyme of the closest source section; keep POV, tense and register.
5. Echo one recurring image from the source, then move it forward.
6. Do not repeat the source's lines; do not contradict its facts.

## Placement in `structure.md`

Where the new section sits is set by `structure.md`; if the user asks for a section the structure lacks, report that `structure.md` needs the entry rather than editing it.

## Length

Match the line count of the source section of the same kind. Bridges are usually the shortest main section; pre-choruses are usually two to four lines.

## Pitfalls

- A bridge that restates the chorus.
- A final verse that explains what earlier verses already implied.
- A pre-chorus that resolves the tension.
- A new verse written in a different register than the source.
