# Skill: On This Day

## Trigger

Use this skill only when the user explicitly asks about events tied to a specific calendar date — e.g. "what happened on today's date," "what does the church calendar mark today," "on this day in church history," or similar. Do not invoke this automatically as part of the general sermon-building workflow.

## What it does

Given a date (default: today's date, or a date the user specifies), identify:

- **Liturgical calendar entries** — feast days, saints' days, or observances marked on this date in recognized Christian calendars (e.g. the Revised Common Lectionary, the Western liturgical calendar, or relevant Protestant observances). Cite the specific calendar/source used.
- **Documented historical church events tied to this date** — actual dated events (e.g. a council decision, a reformer's documented act, a translation milestone) with a citable historical source. Do not include undated or loosely-dated traditions as if they were fixed to this day.
- **Jewish calendar correspondences, if relevant and requested** — e.g. what this date corresponds to on the Hebrew calendar and any associated observance, citing the correspondence clearly (Gregorian date is not fixed relative to the Hebrew calendar year over year, so state the specific year being referenced).

## Standards

- Same non-invention rule as the core project: if no dated, sourced event exists for that date, say so rather than manufacturing one.
- Always cite the specific calendar, source, or historical reference used.
- Present findings as a list the user can choose from, consistent with the shortlist-then-pick pattern used elsewhere in this project, if the user's goal is to build a sermon from one of these entries.
