# Original Language: Greek and Hebrew/Aramaic Handling

How to bring the original text into a sermon without losing the reader.

## The Rule

Everything must align with the actual text in its original language. English may be used only where it does not deviate from the original in thought, meaning or context. Where a translation choice is contestable, or a key term carries meaning lost in English, note the original word and its sense.

## How to Present a Term

For every original-language term you mention, give all four:

1. **The English word** the reader knows, in quotation marks, with the verse
2. **The transliterated term** in italics (Latin letters, no Greek or Hebrew script required; add the script after it if helpful)
3. **Its sense** in plain words, in a short phrase
4. **The lexicon** that supports the sense, named (BDAG, HALOT, Strong's, BDB, TDNT, TDOT as appropriate)

Example shape: "Home" (John 14:23) translates *mone* (Greek: a place to stay). BDAG gives "room, dwelling place" for the noun.

Never state a sense you have not checked in a real lexicon. If you cannot check one, mark the claim **unverifiable** and leave it out of a draft.

## Transliteration

- Use one consistent scheme through a document (e.g. *shalom*, *ruach*, *agape*). Do not mix schemes
- Mark vowel-length or special letters only if it helps the reader
- Give the Hebrew root only when the sermon uses it, and say what a root is on first use ("the three-letter core of a Hebrew word")

## Lexicon Use

| Language | Preferred sources |
|---|---|
| Greek (NT) | BDAG (*A Greek-English Lexicon of the New Testament*), Louw-Nida for semantic domains, TDNT for background |
| Hebrew/Aramaic (OT) | HALOT (*Hebrew and Aramaic Lexicon of the Old Testament*), BDB, TDOT |
| Septuagint (Greek OT) | LSJ for classical sense; Lust-Eynikel-Hauspie for LXX Greek |
| Quick check | Strong's and Blue Letter Bible or Bible Hub for an index only; they are not primary lexicons |

- Prefer a primary lexicon over a general website. Strong's is acceptable for locating a word; it is not enough to support a nuance
- Name the lexicon every time; "the lexicons say" is not a citation
- Cite by headword (s.v. = "under the word"), not by invented page number

## Word Studies: Common Traps

Check each of these before using a word study. Well-known examples are "Abba means Daddy" and "agape is God-love, phileo is brotherly love"; confirm any such claim in a primary lexicon before using it.

- **Etymological fallacy:** a word's history does not fix its meaning in a given verse. Meaning comes from use in context
- **Root fallacy:** a shared root does not mean shared sense
- **Illegitimate totality transfer:** do not load every sense of a word into one verse
- **Overloading a synonym pair:** two verbs in one passage do not always carry two meanings
- **Folk etymology:** a catchy "the Greek really means..." is false until a lexicon supports it

## Translation Choices

- Say which translation you quote, once, at the start
- If you change translation mid-document, mark it ("NIV here", "my rendering from the Greek")
- Where translations differ in a way that matters, show both readings and say which the Greek or Hebrew supports
- Give your own rendering only when you can defend it from the text and lexicon

## Septuagint and Quotation

- The NT often quotes the Greek OT (the Septuagint, LXX), which can differ from the Hebrew (Masoretic Text, MT). When the NT quotes the OT, say which text-form it follows
- Label **quotation** (explicit citation), **allusion** (clear reference), **echo** (shared theme or wording). Do not upgrade an echo to a quotation (guardrail 8)

## When the Text Is Uncertain

- Name manuscript variants only when you can cite a critical edition (NA28 or UBS5 for Greek; BHS or BHQ for Hebrew)
- If you cannot confirm a variant, leave it out, and say so in "Gaps"
