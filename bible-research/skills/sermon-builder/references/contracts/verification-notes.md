# Contract: Verification Notes

The closing section added by the verification gate to **every** in-scope response: shortlist, breakdown, draft and revision. It must appear with no exceptions, even as one line. Modeled on the notes in `source/sample-shortlist-ezekiel.md`.

## Template

```markdown
**Verification notes:**
- **Checked:** [WHAT WAS CHECKED, IN PLAIN WORDS: REFERENCES, ORIGINAL-LANGUAGE TERMS, LEXICON ENTRIES, JEWISH SOURCE CITATIONS]
- **Corrected:** [WHAT WAS FIXED AND HOW, ONE LINE EACH]
- **Reworded:** [PHRASING SOFTENED TO TRACK THE SOURCE]
- **Contested (kept, framed as contested):** [POINTS]
- **Removed:** [CLAIM] - no citable source could be found to support it.
- **Not settled / not confirmed:** [WHAT COULD NOT BE CONFIRMED AND WHY]
```

## Rules

- **Minimum one line.** If nothing needed correction, write exactly: **Verification notes:** All claims checked and verified against source - no corrections needed.
- Omit a bullet that has nothing to report, except in the all-clear case
- Plain language. A short summary of changes, not a re-run of the full verification report
- Never name an internal draft, an agent, or a verdict table
- Say what was removed in a form the user can understand ("Removed: the idea that X; I could not trace it to any source")
- Say what could not be confirmed (for example a lexicon count not re-checked line by line) rather than implying it was
- Never claim a check that was not performed
