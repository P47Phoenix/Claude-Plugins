# Contract: Delivery Notes

Emitted by `sermon-verification` task type `pacing`. A list of delivery notes. On demand only; not part of the gate.

## Template

```markdown
# Delivery Notes (Oral Delivery and Pacing)

**Estimated spoken length:** [MINUTES] at about 130 words per minute  |  **Target:** [STATED TARGET OR "none given"]

## [N]. [SHORT LABEL]
- **Section:** [WHERE IN THE SERMON]
- **Issue:** [WHAT WOULD TRIP UP A LISTENER OR SPEAKER]
- **Suggested edit:** [SPECIFIC REWORDING, RESTRUCTURING, OR PACING NOTE, WRITTEN OUT SO IT CAN BE APPLIED DIRECTLY]

## Balance
[EXPOSITION / ILLUSTRATION / APPLICATION: APPROXIMATE SHARE AND WHERE IT IS LOPSIDED]

## Summary
[ONE PARAGRAPH, PLAIN LANGUAGE: THE THREE CHANGES THAT HELP MOST]
```

## Rules

- Focus on deliverability, not theological content. Leave doctrinal and factual concerns to the other checks; if a fact looks wrong, say in one line that it should go to `cite`, `history` or `redteam`
- A suggested edit is concrete. "Tighten this up" is not acceptable
- Give the replacement text where a rewrite is suggested, in plain language and short sentences (guardrail 6)
- Do not change a scripture reference, quotation or source while editing for sound
