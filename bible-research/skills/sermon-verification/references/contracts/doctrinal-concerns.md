# Contract: Doctrinal Concerns

Emitted by `sermon-verification` task type `doctrine`. A list of doctrinal concerns.

## Template

```markdown
# Doctrinal Concerns

**Lens applied:** [CORE PROTESTANT DISTINCTIVES, OR THE TRADITION THE USER NAMED]
**Concerns:** [COUNT]  |  Incorrect: [N]  Contested: [N]  Internal contradiction: [N]  Jewish material: [N]

## [N]. [SHORT LABEL]
- **Claim/section:** [WHAT IS BEING FLAGGED, WITH LOCATION]
- **Concern:** [THE DOCTRINAL ISSUE OR CONTESTED POINT]
- **Type:** [incorrect / contested across traditions / internal contradiction / Jewish material misrepresented]
- **Context:** [DENOMINATIONAL FRAMING NEEDED, NAMING THE TRADITIONS AND POSITIONS; OR THE CORRECTION IF IT IS A PLAIN INTERNAL CONTRADICTION]

## Summary
[ONE PARAGRAPH, PLAIN LANGUAGE]
```

## Rules

- Keep **incorrect** and **contested across traditions** apart. They are different findings (guardrail 10)
- "Incorrect" is reserved for a claim that contradicts the text or a core distinctive shared across the Protestant mainstream. Where unsure, use "contested"
- Name the traditions and positions in "Context" for each contested point (for example Reformed and Arminian views of election)
- Do not assert that no tradition holds a position unless certain (no invention)
- A contested point is framed as contested in the draft, not removed (guardrail 4)
- Flag Jewish material that misrepresents Jewish belief or practice, or that cites no source (guardrail 3)
- Do not flag metaphor or devotional language as error (guardrail 11)
